
# E-Commerce Data Analysis

## About the Project

This project is based on the Olist Brazilian E-Commerce dataset. The aim is to analyse e-commerce data and understand sales trends, product performance, customer reviews, and delivery performance.

I am using this project to gain practical experience in data cleaning, SQL queries, data analysis, and dashboard creation.

## Tools & Technologies

* **Python** — Data cleaning and analysis
* **Pandas** — Data manipulation
* **Matplotlib** — Data visualization
* **MySQL** — Querying data and answering business questions
* **Power BI** — Interactive dashboard
* **Streamlit** — Web-based analytics dashboard

## Dataset

The project uses the publicly available Olist Brazilian E-Commerce dataset.

[Dataset Link – Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

The dataset includes information about orders, customers, products, payments, sellers, and customer reviews.

## Project Goals

* Understand monthly sales and order trends.
* Identify product categories with high sales.
* Analyse customer reviews and ratings.
* Check delivery times and late deliveries.
* Use SQL to answer business-related questions.
* Present important findings through dashboards.

## Project Workflow

1. Collect and understand the dataset.
2. Check data quality and handle missing or duplicate values where appropriate.
3. Clean and prepare the data using Python.
4. Perform exploratory data analysis.
5. Write SQL queries to analyse business performance.
6. Create dashboards using Power BI and Streamlit.
7. Summarize the findings and suggest possible improvements.
