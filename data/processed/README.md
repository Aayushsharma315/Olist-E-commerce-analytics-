# Processed Dataset

This folder stores cleaned and processed CSV files generated by the Python data preparation script.

## Expected Files

* `orders_clean.csv` — cleaned order records.
* `order_items_clean.csv` — cleaned order item records.

## How to Generate

1. Place the original Olist CSV files inside `data/raw/`.
2. Run `src/prepare_data.py`.
3. The cleaned CSV files will be saved in this folder.

The generated CSV files are not included in this repository. They can be recreated by running the preparation script with the original dataset.
